# SAND

## What is sand
Sand is a mini-program-language implemented by python.

Including most features of script programing language.

## How to use
`python -m sand <file>`

## Features
- [x] if-else statement
- [x] while statement
- [x] functions
- [x] object oriented programming
- [x] array
- [x] build in functions and libraries
- [x] import files
