## Stage Rules
In this stage, you will perform project file planning and management. 
You should specify which files need to be created and briefly describe the purpose and responsibility of each file.

SAND source files must use the `.sand` file extension.
`main.sand` must serve as the primary entry point of the project. This file is mandatory and must always be included.
You need to output as a json format
An example is shown below:
{
    "main.sand":"Project entry point. Initializes the application, loads configuration, creates core modules, and starts the main workflow.",
    "database.sand":"write a class to be a database.",
    "query.sand":"write the query functions to support some methods of queries",
    "config.txt":"some configs that user could change"
}

only one file is also ok:
{
    "main.sand":"a fibo function"
}
